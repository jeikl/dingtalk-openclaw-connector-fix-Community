# Release Notes · v0.8.28

**发布日期：** 2026-07-25  
**npm：** `@jeik/dingtalk-connector@0.8.28`  
**定位：** 基于官方 **0.8.24**，叠加本仓库独有优化的正式版

---

## 一句话

连接更稳、消息更少丢、模型出错时提示更清楚；官方 0.8.24 的长连接改进已吸收，**本仓库独有**的图片/答案卡等优化继续保留。

---

## 基于官方 0.8.24 做了什么

- 吸收官方对长连接的稳定性改进（少假死、少误重连）
- 长任务处理期间连接更不容易被中途打断
- 日志更干净，方便运维判断「是不是真坏了」

未合入：官方给其他插件调用的「卡片开放接口」（对话主流程不需要）。

---

## 本仓库额外优化（效果）

1. **真正能收消息才显示已连接** — 减少「显示在线、发了没反应」  
2. **连发 / 错误后 / 刚回完再发** — 消息进网关的成功率明显提高  
3. **上一条还在跑时再发** — 更容易马上看到排队提示和思考中表情  
4. **模型 503、欠费、无可用线路等** — 更容易定格成中文错误说明，少卡转圈  
5. **本仓库独有能力** — 大段答案独立卡片、图片全路径、中文错误映射等均保留

## 安装

```bash
npx -y @jeik/dingtalk-connector@0.8.28 install --force
openclaw gateway restart
```

或：

```bash
openclaw plugins install @jeik/dingtalk-connector@0.8.28 --force
openclaw gateway restart
```

---

## 建议验收

1. 启动后日志出现「订阅已生效 / registered」类成功信息后再发消息  
2. 正常对话：先「召唤大模型」再流式/答案卡  
3. 故意用故障模型：应定格中文错误，而不是一直转圈  
4. 任务进行中再发一条：应较快出现排队/处理中反馈
